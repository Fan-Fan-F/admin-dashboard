# ShopPulse · 电商数据看板

零依赖的电商管理后台经营看板，原生 Canvas 手绘图表（不引任何图表库），
打开 `index.html` 即可运行。

## 功能

- KPI 卡片：销售额 / 订单量 / 客单价 / 转化率，与上周期环比（涨红跌绿）
- 销售额 & 订单量双轴折线趋势图（7/30/90 天切换，渐变面积填充）
- 品类销售占比环形图 + 图例
- 热销商品 TOP 5 排行
- 最新订单列表（状态标签：已支付/已发货/待付款/退款中）
- 演示数据用可复现伪随机生成（含周末效应、促销脉冲、增长趋势）
- 响应式，HiDPI 清晰渲染

## 设计参考

参考了 medusa admin / bagisto 后台的信息层级与 nopCommerce 的报表布局，
以零依赖方案重新实现，图表引擎（`charts.js`）可独立复用。

## 运行

浏览器直接打开 `index.html`。
